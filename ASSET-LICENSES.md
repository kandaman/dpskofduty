## Policy

1. Every external asset is recorded in this file.
2. No asset is used unless its license allows this project's use.
3. No copyrighted, ripped, or paid assets are ever used.
4. CC-BY assets are acceptable if correctly attributed; CC0 is preferred.
5. Any asset whose license is unclear or source cannot be verified must be removed from production use.
6. This file is the authoritative license record — if an asset is not listed here, its license has not been verified.
